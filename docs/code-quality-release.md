# تحسين بنية الكود وأمانه

هذه التغييرات تحافظ على صفحات BALANCE ووظائفها، وتفصل مسؤوليات الكود دون تغيير مخطط قاعدة البيانات أو بيانات العمل.

## التغييرات المنفذة

- فصل صفحات المواد والمخزون والطلبات إلى نماذج وعرض وخدمات ومحررات مستقلة؛ تظل أسماء ملفات الدخول والصفحات العامة متوافقة.
- فصل التخزين المحلي للمسودات، واستعادة محاولات الحفظ، وتخزين الصور إلى وحدات قابلة للاختبار عبر اعتماديات صريحة.
- منع تنفيذ HTML من نصوص وملفات الاستيراد باستخدام خلايا DOM نصية، وترميز قيم العرض والروابط في الوحدات المفصولة.
- توحيد SheetJS على نسخة محلية 0.20.3، مع ترخيصها وبصمة تحقق؛ إزالة الاعتماد على نسخ Excel القديمة من CDN.
- توحيد تحويل الأرقام العربية والفارسية والتواريخ، ورفض الفراغات والتواريخ المستحيلة والكسور في الحقول الصحيحة، مع الحفاظ على الصفر وتواريخ ISO الصحيحة.
- توحيد pagination وعناوين استيراد الوحدات، وإظهار أخطاء الاستعلام بدل تفسيرها كبيانات فارغة.
- تجميع تحديثات المطابقة واستعلامات التكرار، وتحديد التزامن، ومنع تكرار إنشاء حزمة عند فقد رد الشبكة بإتاحة مراجعة المعرّف المعروف.
- استخدام ملخص المخزون الموجود لتحميل كتالوج الطلبات بدل تنزيل سجل الحركات كاملًا.
- توحيد تحميل أداة تصدير الصور مع SRI ومهلة وإعادة محاولة، وتنظيف الصور المؤقتة وموارد التصدير.
- حذف ثلاث وحدات JavaScript قديمة وخمسة ملفات CSS غير مرتبطة بالصفحات، واستخراج tokens وتوحيد التنسيق.
- إضافة ESLint وPrettier وفحص مراجع الملفات وبصمة المكتبة، وخادم معاينة محلي، ومسار GitHub Actions للتحقق.
- إزالة اختبارات اقتطاع الدوال وتقييمها كنص في أجزاء المسودات والصور والتسوية، واستبدالها باختبارات API مباشرة.
- إضافة fixture محلية تشغّل جميع ملفات الترحيل التسعة وملفي SQL الاختباريين دون أي اتصال بالإنتاج.

## التحقق

- `npm run check`: ناجح، بما فيه ESLint دون تحذيرات، والتنسيق، و505 مراجع ملفات محلية وبصمة SheetJS.
- `npm test`: 108 اختبارات ناجحة، دون فشل أو تخطٍ.
- `npm run test:browser`: 23 اختبار Chromium ناجحًا على واجهة التطبيق الفعلية مع بديل API محلي؛ تشمل حماية صفحات الدخول، تهيئة 19 صفحة، ترميز الاستيراد وقراءة/كتابة Excel، وعرض الدخول عند 390 و1440 بكسل.

اختبارات المتصفح تستخدم جلسات وبيانات وهمية وتحجب الشبكة الخارجية. وهي لا تدّعي اختبار بريد الدعوات أو جلسات الإنتاج أو خدمات Supabase الفعلية. fixture PostgreSQL تمثل مخطط التطبيق اللازم للترحيلات، وليست نسخة كاملة من منصة Supabase، ولا تثبت سلوك جلسات PostgreSQL المتزامنة.

## المراجعة والنشر

التغييرات تُسلَّم عبر فرع وطلب مراجعة. دمج الطلب ونشر الموقع خطوة لاحقة؛ لا تنفّذ ترحيلات قاعدة بيانات أو تعيد نشر Edge Functions من أجل هذا التعديل. ملفات الترحيل الحالية لم تتغير. تنسيق مصدر Edge Function لا يستدعي نشرها.
